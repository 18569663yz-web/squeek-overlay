# Squeek 透视标记（squeek.win 油猴脚本）

给 [squeek.win](https://squeek.win)（Exsqueektion）手动游玩用的只读信息标记脚本。
只显示服务器本来就发给游戏客户端的数据，帮你一眼找到大货、武器和回血食物在哪。

当前版本：v3.0（精简版，专为不卡游戏设计）

## 标记内容

只标这几类，别的一律不显示：

| 标记 | 内容 |
|---|---|
| 冠 / 皇 / 像 / 匣 | 400 分以上物品：王冠、皇家王冠、极·神像、精/极·圣匣 |
| 砍 | 砍刀 |
| 食 | 食物 snack（能吃回血的就是它；心果不能吃，不显示） |
| 库 / 门 / 牢 / 桥 | 保险库、传送门、地牢入口、桥捷径（地图结构） |

显示方式：

- 右上角全图小地图（带地形：水、树篱、石头、桥；进地牢后自动切换成地牢内部图，含出口和深层楼梯）
- 屏幕内物品画圈标名称和距离，屏幕外物品在屏幕边缘画方向箭头
- 左上角一行状态：大货 / 砍刀 / 食物的数量和最近距离

不检测敌人。没有自动驾驶、没有自动操作。

## 安装

1. 浏览器装 [Tampermonkey（油猴）](https://www.tampermonkey.net/) 扩展。
2. 打开本仓库的 `squeek-overlay.user.js`，点 **Raw**，油猴会自动弹出安装确认；或者在油猴里「新建脚本」，把文件内容整份粘进去，`Ctrl+S` 保存。
3. Edge 浏览器注意：打开 `edge://extensions/`，进 Tampermonkey 的「详细信息」，打开 **「允许用户脚本」** 开关，否则脚本不生效。
4. 打开 https://squeek.win 开一局，进局后自动生效，不用任何设置。

## 快捷键

| 键 | 作用 |
|---|---|
| `M` | 开 / 关小地图 |
| `B` | 切换小地图大小 |
| `H` | 隐藏 / 显示全部标记 |
| `+` / `-` | 标定屏幕圈大小（见下） |
| `0` | 重置标定 |

### 屏幕圈标定（只需做一次）

小地图和方向箭头开局就是准的。屏幕内的圈位置靠一个缩放系数，默认 1:1 粗略可用；想更准：找一个标记物走到它旁边，圈没套住就按 `+` / `-` 微调到套住为止。设置存在浏览器本地，之后每局自动沿用。

## 性能

- 绘制约 8 帧/秒，画布分辨率封顶，不跟游戏抢性能
- 脚本只监听游戏的 WebSocket 消息，零发送、零额外请求
- 还觉得卡：按 `B` 把小地图调小，或按 `M` 关掉小地图

## 工作原理（简述）

游戏开局时服务器会把整张地图的地面物品、保险库位置和地形发给客户端（这是游戏本身的机制）。脚本在游戏建连前挂上监听，把这些数据画成标记。不修改任何游戏数据，不发送任何游戏指令，所有数值仍然由服务器计算。

## 更新

游戏发新版后标记可能失效（数据格式变了）。把仓库里的脚本换成新版文件，油猴里整份覆盖粘贴、`Ctrl+S`、刷新游戏即可。

## 说明

- 本脚本仅供个人学习与自用，使用风险自担。
- 分数、血量、伤害全部由游戏服务器计算，本脚本不提供也做不到任何数值修改。
